# NANA Website

Sitio web fan dedicado a **NANA**, la obra de Ai Yazawa. El proyecto presenta a sus personajes, la historia, las bandas y la música de la serie mediante una experiencia visual inspirada en su estética.

## Página web

Visita la versión publicada:

**https://nana-webside.netlify.app**

## Contenido

- Página de inicio con una introducción a la historia.
- Catálogo de personajes organizado por categorías.
- Ficha detallada de cada personaje.
- Página de historia con sus acontecimientos principales.
- Página de música con reproductor y canciones de BLACK STONES y TRAPNEST.
- Secciones dedicadas a BLACK STONES y TRAPNEST.
- Cambio de idioma entre español e inglés.
- Diseño responsive para ordenador, tablet y móvil.
